Плашка сообщения

Поле ввода оформлено как сообщение в чате. Устроено как TextBox: значение хранит скрытое поле формы, ввод ведёт RichEditor. Панель форматирования со вставкой смайлика показывается над плашкой при фокусе, Enter создаёт новый абзац, а не отправляет форму. 


			

		

	


	

		
С готовым значением

		

			Значение хранится разметкой мессенджеров, а не HTML: **жирный**, _курсив_,
			~зачёркнутый~, __подчёркнутый__. Enter даёт один перенос
			(\n), два нажатия — пустую строку (\n\n). Спинтакс
			[раз|два] и переменные {ИМЯ} подсвечиваются в тексте, но в значение уходят
			как есть — подсветка это обычные span, которые сериализация отбрасывает.
		

		

			

				
				

			

		

	


	

		
Переменные из разметки

		

			Персонализация по умолчанию выключена: без неё нет ни кнопки в панели, ни подсветки. Включает её
			опция personalization, атрибут data-personalization или само объявление
			списка переменных — им она и включена во всех полях этой страницы. Список можно не
			передавать в опциях, а объявить атрибутом
			data-variables поля-носителя — когда разметку отдаёт сервер. Две формы: ключи через запятую
			(data-variables="ИМЯ, ГОРОД") или массив JSON, если у переменных есть названия. Переданный
			в опциях список имеет приоритет над атрибутом. Во втором поле переменных нет вовсе, а текст в окне
			задан атрибутом data-variables-empty: причину пустого списка знает приложение.
		

		

			

				
				

			

			

				
				

			

		

	


	

		
Цитата и блок кода

		

			Блоки по умолчанию выключены — их понимает не каждый канал. Здесь они объявлены атрибутом
			data-blocks="quote code". Моноширинный и блок кода делит одна кнопка: выделена
			одна строка или её часть — моноширинный, несколько строк (или ничего не выделено) — блок.
			Enter внутри блока заканчивает его,
			Shift+Enter переносит строку внутри, Backspace в начале блока возвращает обычный
			текст. В значении цитата — это > в начале каждой строки, блок кода — ограждение
			из трёх обратных кавычек; внутри кода разметка не разбирается, а отступы сохраняются.
		

		

			

				
				

			

		

	


	

		
Показ выхода

		

			Переключатель над плашкой показывает значение так, как оно уйдёт в форму, — разметкой
			мессенджеров. По умолчанию его нет: пишущему сообщение сырая разметка не нужна. Включается
			опцией source или атрибутом data-source. Панель показывается вместо
			плашки и только показывает: текст в ней выделяется и копируется, а правится сообщение
			по-прежнему в плашке.
		

		

			

				
			

		

	


	

		
Состояния

		

			required, readonly и disabled берутся у поля-носителя, как у
			остальных контролов кита. Кнопка проверяет валидацию формы.
